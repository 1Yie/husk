Unmodified font and icon definitions from Microsoft's VS Code repository:

`https://github.com/microsoft/vscode/tree/b3ff02a27ab7884ad0556a8049f3f35758481b1d/extensions/theme-seti`

- `seti.woff` SHA256: `b127762058f89b37b08d76185e3b0558f5c28859e39a3840a27cb28b9739d6e2`
- `vs-seti-icon-theme.json` SHA256: `2088843e6f00a81870ed2890132fb658cf33406177a5dd58c9c7001e5184ca2a`

The icons originate from Seti UI by Jesse Weed and are MIT-licensed.
Original notices are retained here. Combined notices also ship in
`public/licenses/vscode-seti.txt`, which Vite copies into the desktop bundle.

No runtime network request or new icon-package dependency is required.
